# แบบบันทึก ชั่วโมง นศท. จิตอาสา
## โรงเรียนพานทองสภาชนูปถัมภ์ ประจำปีการศึกษา 2569

เว็บไซต์ระบบบันทึกชั่วโมงจิตอาสา นักศึกษาวิชาทหาร (นศท.) โรงเรียนพานทองสภาชนูปถัมภ์ พัฒนาขึ้นโดยถอดแบบโครงสร้าง คำถาม ลำดับหน้า เงื่อนไขการข้ามหน้า (Branching Logic) และตารางสรุปชั่วโมงเวรจราจรแบบ Google Sheets ตามไฟล์ต้นฉบับอย่างสมบูรณ์แบบ 100%

---

### 🌟 จุดเด่นและฟังก์ชันการทำงาน

1. **ถอดแบบตามต้นฉบับอย่างแม่นยำ:**
   - **ทางเลือกที่ 1: "ส่วนตัว"**
     - ระบุชั้นปี (ปีที่ 1, 2, 3), คำนำหน้า (นศท.ชาย, นศท.หญิง), ชื่อ - นามสกุล
     - สถานที่ทำจิตสาธารณะ (ภายในสถานศึกษา, นอกสถานศึกษา, อื่นๆ)
     - วันที่และเวลาเริ่มทำจิตอาสา
     - คำนวณชั่วโมงจิตอาสา (เวรจราจร = 30 นาที ลง 0.5 ชม., นอกสถานที่ = 3 ชม.)
     - อัปโหลดรูปภาพหรือคลิปวิดีโอหลักฐาน
     - ระบุหมายเหตุและวิธีการแก้แฟลต
   - **ทางเลือกที่ 2: "บันทึกเวรจราจร"**
     - เลือกระบุกลุ่มวัน (จันทร์, อังคาร, พุธ, พฤหัสบดี, ศุกร์)
     - หน้าเช็คยอดแยกตามชั้นปี **ปี 1, ปี 2, ปี 3** ครบทุกวัน พร้อมรูปถ่าย นศท. ครบถ้วน 75 ภาพ
     - **ระบบเช็คชื่อระบุเวลามา:** เมื่อกดติ๊กเลือก นศท. ระบบจะตั้งเวลามาเป็น **06:30 น.** ให้อัตโนมัติทันที พร้อมมีช่องเลือก/ปรับเวลามาของแต่ละคนได้อย่างอิสระ (และมีตัวตั้งเวลาเริ่มต้นส่วนกลางในแถบเครื่องมือ)
     - มีตัวเลือกช่วงเวลา: **"เช้า"**, **"บ่าย"**, และ **"อื่นๆ"**
     - บันทึกวันที่ปฏิบัติหน้าที่, รูปถ่ายขณะปฏิบัติหน้าที่, และหมายเหตุ

2. **ระบบตารางชั่วโมงเวรจราจรแบบ Google Sheets (Sheets Matrix):**
   - ถอดแบบสี หัวตาราง (`#356854`) ป้ายสีประจำกลุ่มเวรวัน และการจัดกลุ่ม นศท. ชาย/หญิง ตามชั้นปี ครบ 92 นาย
   - **เกณฑ์การคำนวณชั่วโมง:**
     - ปฏิบัติหน้าที่ตอนเช้า = **0.5 ชม.** (30 นาที)
     - ปฏิบัติหน้าที่ตอนบ่าย = **0.5 ชม.** (30 นาที)
     - หากมีการลงระบบทั้งเช้าและบ่ายในวันเดียวกัน = **0.5 + 0.5 = 1 ชม.** (แสดงตัวเลข 1 สีเหลืองเด่นชัด)
   - คอลัมน์ **"รวม ชม."** คำนวณผลรวมสะสมอัตโนมัติแบบเรียลไทม์
   - สามารถเลือกดูตามชั้นปี (ปี 1, ปี 2, ปี 3 หรือทั้งหมด), กรองตามกลุ่มเวรวัน, และค้นหาตามชื่อได้
   - ตรึงคอลัมน์ชื่อและรวม ชม. ด้านซ้าย (Sticky Columns) เหมือน Google Sheets จริง
   - ปุ่ม **"ส่งออกตาราง Excel"** ดาวน์โหลดไฟล์ Spreadsheet พร้อมภาษาไทยสมบูรณ์ (UTF-8 BOM)
   - ข้อความติดต่อท้ายตาราง: *ติดต่อแจ้งปัญหาได้ที่ น้ำเหนือ หรือ กีต้า*

3. **ความยืดหยุ่นในการใช้งาน:**
   - **โหมดเปิดดูโดยตรง (Offline / Standalone):** ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge, Safari, Firefox) ใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรม ข้อมูลจะบันทึกในเครื่องอัตโนมัติผ่าน `LocalStorage`
   - **โหมดเซิร์ฟเวอร์ (Node.js Server):** มี REST API และบันทึกข้อมูลลงไฟล์ `data/submissions.json` ถาวร

### 🚀 วิธีการเปิดใช้งาน

#### วิธีที่ 1: เปิดใช้งานทันที (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์ **`index.html`** ในโฟลเดอร์นี้เพื่อเปิดใช้งานบนเว็บเบราว์เซอร์ได้ทันที

#### วิธีที่ 2: รันผ่าน Node.js Server
1. เปิด Command Prompt หรือ PowerShell ในโฟลเดอร์นี้
2. รันคำสั่ง:
   ```bash
   npm start
   ```
   หรือ
   ```bash
   node server.js
   ```
3. เปิดเว็บเบราว์เซอร์ไปที่: [http://localhost:3000](http://localhost:3000)
